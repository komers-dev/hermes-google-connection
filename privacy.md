# Политика работы с данными

Hermes Personal — личная локальная настройка помощника. Этот сайт содержит только описание подключения и документы; содержимое почты, календарей и данные входа на сайт не загружаются.

## Доступ к Google

После согласия владельца помощник получает доступ к выбранному аккаунту Gmail и Google Calendar. Разрешения позволяют читать письма, работать с их состоянием и ярлыками, создавать и изменять письма через поддерживаемые функции Gmail, читать список календарей, читать и изменять события. Эти права не дают подключению доступ к Google Drive, контактам, таблицам или документам.

Для утреннего обзора используется ограниченная выборка недавних цепочек из входящих и события выбранных календарей на текущий день. Вложения не читаются. Рассылки и обнаруженные письма с кодами входа исключаются; тексты могут сокращаться. Отбор важных писем и приоритетов является оценкой модели.

## Использование и передача

Данные нужны для обзора почты, планирования дня и выполнения запросов владельца. Для подготовки ответов выбранные фрагменты передаются поставщику модели; текущая модель работает через OpenAI. Готовые отчёты направляются в личный Telegram-чат владельца. Утреннее задание работает без инструментов изменения данных и без внешней памяти.

В обычных диалогах локального Hermes могут быть включены другие поставщики моделей и внешняя память. Тогда сведения из диалога могут обрабатываться настроенным поставщиком памяти; текущая установка использует Mem0 с моделью через glm5.app и локальное хранилище. Поэтому перед работой с Google в обычном диалоге владелец учитывает настройки модели, памяти и доставки.

Данные не публикуются на этом сайте и не продаются. Для Google API действуют [Google API Services User Data Policy и требования Limited Use](https://developers.google.com/terms/api-services-user-data-policy). Передача поставщикам моделей предназначена для запрошенных функций личного помощника, а не для создания общедоступной базы переписки.

## Хранение и удаление

Данные входа Google хранятся локально в защищённых файлах установки Hermes. История диалогов, результаты заданий и записи памяти могут сохраняться в локальном хранилище; копии доставленных отчётов остаются в Telegram. Срок хранения локальных данных определяет владелец установки. Поставщики моделей и доставки обрабатывают переданные им данные по своим действующим правилам.

Владелец может отозвать доступ в разделе сторонних подключений аккаунта Google, отключить задания Hermes, удалить локальные данные и отчёты в Telegram. Отзыв доступа прекращает новые обращения к Google, но сам по себе не удаляет ранее сохранённые отчёты и память.

Оператор доступен через адрес поддержки на экране разрешений Google. Публичной регистрации других пользователей в этой установке нет.
